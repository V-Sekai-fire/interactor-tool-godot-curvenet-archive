# interactor-tool-godot-curvenet-archive

Retired solver families from interactor-tool-godot-curvenet, kept as Lean specifications, C++ mirrors and their tests.

## Use

Each solver here was once on the production path of [interactor-tool-godot-curvenet](https://github.com/V-Sekai-fire/interactor-tool-godot-curvenet) and was retired after measurement showed it could not meet that project's performance targets. A `TOMBSTONE` header at the top of a file records what failed and the diagnostic that showed it, so the same path is not tried again.

## Build and run

Nothing here builds on its own. The files are a record, read alongside the parent project.
